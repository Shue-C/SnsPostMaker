---
description: 承認済みの投稿を Bluesky / X に自動投稿する（IG/Threadsはコピペ用に表示）
---

以下の投稿を公開してください：$ARGUMENTS
（カレンダー上の日付やテーマで指定される。本文が直接渡されることもある）

手順：
1. `data/calendar/` から該当する投稿を探し、本文を確認する。
   ステータスが `投稿予定`（承認済み）でない場合は、先にユーザーに本文を見せて
   承認を得ること。
2. **投稿前に必ず、実際に送信する本文をユーザーに提示して「投稿してよいか」
   最終確認を取る。** 自動投稿は取り消せない操作のため、確認なしに実行しない。
3. 承認されたら実行する：
   - Bluesky: `python3 scripts/sns_post.py bluesky --file <本文ファイル> [--image ... --alt ...]`
   - X: `python3 scripts/sns_post.py x --file <本文ファイル> [--image ... --alt ...]`
   - 本文は一時ファイル（scratchpad）に書き出して `--file` で渡すと安全。
   - 画像はユーザーからパスを受け取る。画像なしの場合はその旨を確認する。
4. Instagram / Threads の分はコードブロックで提示し、手動投稿を依頼する。
5. 投稿に成功したら、返ってきた投稿URLを報告し、カレンダーの該当行を
   `投稿済み` に更新する。
6. 失敗した場合はエラーメッセージをそのまま報告する（`scripts/.env` の
   認証情報不足、X無料枠の上限（17件/24時間・500件/月）超過が典型原因）。

注意：X は無料枠のため投稿数に上限がある。1日に何本も投稿する指示が来たら
上限を伝えて優先順位をユーザーに確認すること。
