description: 承認済みの投稿を Bluesky / X に自動投稿する（IG/Threadsはコピペ用に表示）
---

以下の投稿を公開してください：$ARGUMENTS
（カレンダー上の日付やテーマで指定される。本文が直接渡されることもある）

## 対話セッションで実行する場合

手順：
1. `data/calendar/` から該当する投稿を探し、本文を確認する。
   ステータスが `投稿予定`（承認済み）でない場合は、先にユーザーに本文を見せて
   承認を得ること。
2. **投稿前に必ず、実際に送信する本文をユーザーに提示して「投稿してよいか」
   最終確認を取る。** 自動投稿は取り消せない操作のため、確認なしに実行しない。
3. 承認されたら実行する：
   - Bluesky: `python3 scripts/sns_post.py bluesky --file <本文ファイル> [--image ... --alt ...]`
   - X: `python3 scripts/sns_post.py x --file <本文ファイル> [--image ... --alt ...]`
   - 本文は一時ファイル（scratchpad）に書き出して `--file` で渡すと安全。
   - 画像はユーザーからパスを受け取る。画像なしの場合はその旨を確認する。
4. Instagram / Threads の分はコードブロックで提示し、手動投稿を依頼する。
5. 投稿に成功したら、返ってきた投稿URLを報告し、カレンダーの該当行を
   `投稿済み` に更新する。
6. 失敗した場合はエラーメッセージをそのまま報告する（`scripts/.env` の
   認証情報不足、X側クレジット残高切れ`CreditsDepleted`（HTTP 402）が典型原因）。
   後者の場合は console.x.com の Billing でのチャージをユーザーに依頼する。

注意：X はPay-Per-Use課金（投稿$0.015、リンク付き$0.20）。大量投稿の指示が
来たら概算コストを伝えてユーザーに確認すること。

## Routine（自律実行）で実行する場合

対話ユーザーが存在しないため、上記の「最終確認を取る」手順は行わない。
代わりに以下の条件で機械的に判断する（`CLAUDE.md`の「予約投稿（Routine）」節も参照）：

1. `data/calendar/` の当月・翌月ファイルを走査し、ステータスが **`投稿予定`** かつ
   予定時刻（JST）を過ぎているエントリを探す。`下書き`・`承認待ち`のエントリには
   絶対に触れない（ユーザーの最終承認を経ていないため）。
2. 該当エントリのリンク先（`posts/*.md`）から本文・画像パスを取得し、
   Bluesky・Xそれぞれに `scripts/sns_post.py` で投稿する（本文・画像は一切改変しない）。
3. Instagram・Threadsは自動投稿しない（対象外のまま）。
4. 成功したら該当エントリのステータスを `投稿済み` に更新し、投稿URLを
   ファイルに追記してコミット・プッシュする。
5. 失敗したら（`CreditsDepleted`・ネットワーク拒否等）ステータスは `投稿予定` の
   ままにし、失敗理由と時刻をエントリに追記してコミット・プッシュする
   （次に人間が気づけるようにするため。無限リトライはしない）。
