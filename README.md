# Ceria fi Ixtigna SNS運用チーム 🎩⚙️

ハンドメイドブランドのSNS運用（X / Instagram / Threads / Bluesky）を行う
**Claude Code AIエージェントチーム** です。

## 目的

1. ハンドメイド作品のブランディング・マーケティング向上
2. BOOTH（https://cir.booth.pm/）の売上向上
3. イベント（デザフェス・コミティア・M3 等）の集客

## 使い方

Claude Code（Web・アプリ・CLIいずれでも）でこのリポジトリを開き、
日本語で話しかけるだけです。

### 例

```
/post 新作の真鍮の懐中時計型ペンダント（3,800円）を紹介したい
/plan 8月分のカレンダーを作って。お盆前に新作2点を出す予定
/event デザフェス62 11/21-22 ブースA-123 に出展します
/report 今月のXのフォロワーが+24でした。一番伸びた投稿はimp 5200
```

コマンドを使わず普通に話しかけてもOKです：

```
「今夜投稿する制作過程ネタを1本ください」
「先週の投稿、まだ投稿済みにしてなかったので更新して」
「コミティアの公式タグ、最新の番号を調べて」
```

## チーム構成

| 役割 | 担当 |
|---|---|
| ディレクター | メインのClaude（要望の窓口・全体統括） |
| copywriter | 4SNS分の投稿文の書き分け |
| researcher | トレンド・イベント・タグのWeb調査 |
| planner | 投稿カレンダーの企画・進行管理 |
| analyst | 実績記録・振り返りレポート |

## 最初にやること（セットアップ）

1. **`data/brand.md` を編集**して、【要編集】【要確認】の箇所
   （SNSアカウントID、世界観・口調の調整）を埋める。
   Claudeに「ブランド設定を一緒に埋めて」と頼めば対話形式で設定できます。
2. `/plan 今月分` で最初のカレンダーを作る。
3. あとは投稿したいときに `/post`、イベントが決まったら `/event`。

## 運用の流れ

```
企画（/plan） → 本文作成（/post） → あなたが確認・承認
→ 各SNSへコピペ投稿 → 「投稿した」と報告（カレンダー更新）
→ 数値を報告（/report で振り返り） → 次月の企画へ
```

**Bluesky と X は `/publish` で自動投稿できます**（初回のみ `scripts/README.md` の
手順で認証情報の設定が必要）。Instagram / Threads は手動コピペ運用です。

