# おみくじ画像の仕様

`01.png` 〜 `05.png` が印刷用の画像です（大吉・中吉・小吉・吉・末吉）。
**これらは手で置くファイルではなく、原画から生成したものです。**

## 生成のしかた

原画は `../design/o_01.png` 〜 `o_05.png`（3215×7407）。
次を実行すると、58mm紙の印字幅にあわせた `01.png` 〜 `05.png` が作り直されます。

```bash
cd omikuji
python3 tools/make_print_images.py          # 416ドット幅（58mm紙）
python3 tools/make_print_images.py 576      # 80mm紙にするとき
```

原画を描き直したら、このスクリプトを実行し直してください。
`config.js` の `items[].image` は触る必要がありません。

処理の中身は「縮小 → アンシャープ → レベル補正 → Floyd–Steinberg」です。
原画から印字幅までは約7.7倍の縮小になるので、そのまま縮めると細線が灰色に薄まって
網点になり潰れてしまいます。先に線を締めてから2値化しています。
出力は1bit PNGなので、アプリ側のディザは何もしません（二重処理になりません）。

## 文字の大きさの目安

203dpi のサーマルプリンターで**漢字が読める下限は約24ドット（3mm）**です。
16ドット（2mm）だと画数の多い字は潰れます。

| 印字幅 | 原画（3215px幅）での必要な字の高さ |
|---|---|
| 416ドット（58mm紙） | **185px 以上** |
| 576ドット（80mm紙） | **134px 以上** |

現在の原画の本文は約80px（＝58mm紙で10ドット・1.3mm）なので、
本文と運勢表の文字は**2.3倍ほど大きくする**必要があります。

## 手で画像を用意する場合

原画を使わず直接置くこともできます。その場合の仕様:

| 項目 | 値 |
|---|---|
| ファイル名 | `01.png` 〜（`config.js` の `items[].image` と合わせる） |
| 幅 | **416px ちょうど**（58mm紙・203dpi。80mm紙なら576px） |
| 高さ | 自由 |
| 形式 | PNG（1bitの白黒で作っておくと、意図した通りに刷れます） |

## 絵作りのコツ

サーマルプリンターは **黒か白かの2値**しか印字できません。
中間調は誤差拡散ディザ（網点）に変換されるので、次の点に注意すると綺麗に出ます。

- **線画・ベタ塗り・高コントラスト**が最も綺麗。細い罫線は1px以上の太さを確保する。
- 薄いグレーや淡い色はザラついた網点になる。飛ばしたくない要素は濃い色で。
- **黒ベタの面積が広いと印字が遅く、紙も熱で反る**。背景は白基調、装飾は線で。
- 透過PNGの透明部分は**白**として合成されます。
- 文字は最低でも24ドット（3mm）。明朝の細い線は潰れやすいので太めの字形が安全。

上下の余白は `config.js` の `print.feedUnitsAfter`（印字後の紙送り量）で
調整できるので、画像自体に大きな下余白を入れる必要はありません。

## 印字結果の確認

画像が未設定でも、アプリはIDとラベルだけのプレースホルダーを印刷するので、
画像が揃う前にプリンターとの接続確認ができます。

なお感熱紙の印字は熱・光・経年で薄くなります。長く保管してほしいおみくじなら、
その旨を画像内に一言添えておくと親切です。
