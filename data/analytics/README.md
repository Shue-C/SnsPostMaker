# 投稿実績の記録

analyst が管理する。月ごとに `YYYY-MM.md` を作成して記録する。

## 記録する数値（取れる範囲でよい）

| 目的 | 見る数値 | どこで確認するか |
|---|---|---|
| ブランディング | フォロワー数、いいね、保存数（IG）、プロフィールアクセス | 各SNSのアナリティクス画面 |
| BOOTH売上 | リンククリック、BOOTHアクセス数、注文数、売上 | X/Bluesky のポスト詳細、BOOTHの「アクセス解析」 |
| イベント集客 | 告知投稿のインプレッション・リポスト数、当日の来場反応 | 各SNS＋当日の体感メモ |

## 月ファイルの書式

```markdown
# 2026-07 実績

## 月初スナップショット（毎月1日に記録）
| SNS | フォロワー数 |
|---|---|
| X | 000 |
| Instagram | 000 |
| Threads | 000 |
| Bluesky | 000 |

## 投稿別実績
| 日付 | テーマ | 種別 | SNS | imp | like | RP/保存 | リンクcl | メモ |
|---|---|---|---|---|---|---|---|---|

## BOOTH
| 週 | アクセス | 注文数 | 売上 | メモ |
|---|---|---|---|---|
```

## 運用のコツ

- 全部を毎回記録しなくてよい。**月初のフォロワー数**と、**特に伸びた/沈んだ投稿**
  だけでも記録すれば、analyst が傾向を分析できる。
- 数値はスクリーンショットの読み上げでもOK。「Xのこの投稿、imp 3400 いいね52」
  のように伝えれば analyst が表に整理する。
