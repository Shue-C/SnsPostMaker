# 投稿カレンダーの書式

月ごとに `YYYY-MM.md`（例: `2026-07.md`）を作成する。planner が管理する。

## ステータス

| ステータス | 意味 |
|---|---|
| 下書き | テーマだけ決まっている／本文作成中 |
| 承認待ち | 本文完成。ユーザーの確認待ち |
| 投稿予定 | ユーザー承認済み。日時どおりに投稿するだけ |
| 投稿済み | 投稿完了（ユーザーの報告により更新） |
| 見送り | 中止・延期 |

## 月ファイルの書式

```markdown
# 2026-07 投稿カレンダー

## 第1週（7/1–7/6）

### 07/03（金）21:00 — 新作紹介「{作品名}」
- 種別: BOOTH販促 ／ ステータス: 承認待ち
- 対象SNS: X, Instagram, Threads, Bluesky
- 狙い: 新作の初動売上
- 本文: ↓ / 長い場合は posts/2026-07-03-new-item.md に分離してリンク

（4SNS分の本文をここに記載）
```

## 運用ルール

- 投稿本文が長い場合は `data/calendar/posts/` にファイルを分けてリンクする。
- 投稿済みになったら実績記入の対象になる（`data/analytics/` 参照）。
- 月初に planner が前月の未消化投稿（見送り・下書きのまま）を翌月に繰り越すか
  ユーザーに確認する。
