# テンプレート：BOOTH販促（既存作品の再紹介・再入荷）

用途：新作がない期間の売上維持。過去作品の再紹介、再入荷、購入者の声の紹介。
売り込み色を薄め、「世界観への再招待」として書くこと。

## パターンA：既存作品の再紹介

### X
```
{作品名}、まだ工房に在庫がございます。

{世界観の一文＋どんな人に似合うか（例：旅装に一つ提げるだけで、
歩き慣れた道が異国に変わります。）}

→ https://cir.booth.pm/
#ハンドメイドアクセサリー #ファンタジー雑貨
```

### Instagram
```
{作品名}のこと、あらためて。

{制作時の物語や、写真では伝わりにくい質感・重さ・音などの話（3〜5文）}

{仕様：素材／サイズ／価格}

プロフィールのリンクからお迎えいただけます。

#ハンドメイドアクセサリー #スチームパンクアクセサリー #ファンタジーアクセサリー
#オリジナルアクセサリー #異世界 #handmade
```

### Threads
```
ふと工房の棚を見て、{作品名}の話をしたくなりました。

{制作裏話・気に入っているポイントを会話調で}

BOOTH: https://cir.booth.pm/
#ハンドメイドアクセサリー
```

### Bluesky
```

BOOTHでお迎えいただけます。
https://cir.booth.pm/
```

## パターンB：再入荷

各SNS共通の要素：「ご要望をいただいていた」「数に限りがある」ことを
事実の範囲で淡々と伝える（煽らない）。冒頭を「【再入荷】{作品名}」に
差し替えてパターンAの構成を使う。

## パターンC：お迎え報告への感謝

```
（X/Threads/Bluesky向け）
{作品名}を旅立たせました。お迎えくださった方、ありがとうございます。
{一言（例：新しい持ち主の元で、良い物語の小道具になりますように。）}
```

### 画像の想定
作品写真（過去撮影分の再利用可）。再入荷は在庫が並んだ写真が効果的。
