# テンプレート：新作紹介

用途：新作をBOOTHに出品したとき／イベント新作のお披露目。
`{}` はプレースホルダー。copywriter が作品情報で埋めて仕上げる。

## X（全角140字以内）

```
【新作】{作品名}

{世界観の一文（例：夜の空を閉じ込めた鉱石に、真鍮の羽根を添えました。）}

BOOTHにて本日より → https://cir.booth.pm/
#ハンドメイドアクセサリー #スチームパンク
```

## Instagram（世界観をじっくり・URLなし）

```
【新作】{作品名}

{世界観の物語（3〜6文。どんな旅・どんな持ち主を想像して作ったか、
素材のこだわり、制作の裏話など）}

{仕様：素材／サイズ／価格}

お迎えはプロフィールのリンク（BOOTH）からどうぞ。

#ハンドメイドアクセサリー #ファンタジーアクセサリー #スチームパンクアクセサリー
#スチームパンク #ファンタジー雑貨 #オリジナルアクセサリー #異世界 #handmade
```

## Threads（500字以内・会話調・タグ1個）

```
新作できました。{作品名}。

{制作のつぶやき（例：この歯車の配置、実は3回やり直してます…。
納得いく角度になったので見てほしい）}

BOOTHに出してます → https://cir.booth.pm/

#ハンドメイドアクセサリー
```

## Bluesky（300字以内・落ち着いた文体）

```
新作「{作品名}」をBOOTHに追加しました。

{世界観の一〜二文}

https://cir.booth.pm/
```
