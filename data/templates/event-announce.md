# テンプレート：イベント告知

用途：デザフェス・コミティア・M3 等への出展告知。
公式タグの回次番号は researcher が最新を確認してから使うこと。

## フェーズ1：出展決定告知（3〜4週間前）

### X
```
【出展のお知らせ】
{月日}（{曜日}）開催の {イベント名} に出展いたします。
ブース：{ブース番号}

{一言（例：新作の準備を進めております。続報をお楽しみに。）}

{公式タグ} #ハンドメイドアクセサリー
```

### Instagram
```
【出展のお知らせ】

{月日}（{曜日}）{イベント名} に出展します。
ブース：{ブース番号}

{意気込み・準備中の様子（2〜4文）}

続報はこちらのアカウントでお知らせしていきます。

{公式タグ} #ハンドメイドイベント #ハンドメイドアクセサリー
#スチームパンク #ファンタジー雑貨
```

### Threads
```
お知らせです。{月日}の {イベント名}、出展します！
ブースは {ブース番号}。

{準備のつぶやき}

{公式タグ}
```

### Bluesky
```
{月日}（{曜日}）の {イベント名} に出展します。
ブース：{ブース番号}

{一言}
```

## フェーズ2：新作・頒布物予告（1〜2週間前、2〜3回）

`data/templates/new-item.md` をベースに、文末を
「{イベント名}（{ブース番号}）にてお披露目します」に差し替える。
会場受取とBOOTH後日販売の予定があれば明記する。

## フェーズ3：お品書き・前日案内（3日前〜前日）

### X
```
【お品書き】{イベント名}（{月日}）
ブース：{ブース番号}

{主な頒布物を2〜4点、価格付きで}

画像に全ラインナップをまとめました。お待ちしております。
{公式タグ}
```

（Instagram/Threads/Bluesky も同構成。Instagramはお品書き画像を1枚目に。）

## フェーズ4：当日朝の案内（開場1〜2時間前）

### X
```
{イベント名}、本日 {開場時間} 開場です。
{ブランド名} は {ブース番号} にてお待ちしております。

{目印になる一言（例：歯車と硝子の灯りが目印です。）}
{公式タグ}
```

### 画像の想定
- フェーズ1: 出展告知バナー（ブース番号入り）
- フェーズ3: お品書き画像（全頒布物＋価格）
- フェーズ4: ブース設営写真または目印になるディスプレイ
