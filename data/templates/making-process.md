# テンプレート：制作過程・世界観投稿（ブランディング）

用途：投稿の約50%を占める、売らない投稿。ブランドの世界観を育て、
フォロワーとの関係を作る。ネタ切れ防止のパターン集。

## パターン集（ネタ帳）

1. **素材の物語** … 使っている鉱石・真鍮・硝子がどこから来て、なぜ選んだか
2. **制作途中** … 作業机の上、パーツが並んだ様子、試行錯誤
3. **ビフォーアフター** … パーツの状態 → 完成品
4. **失敗談** … うまくいかなかった話（Threads向き。親近感が湧く）
5. **世界観の断片** … 「この作品の持ち主は、きっと◯◯な人」という設定語り
6. **道具の話** … 愛用の工具・作業環境
7. **季節と作品** … 季節の光・空気と作品を絡めた写真と一言

## X（サッと読める一枚＋一言）

```
育てる派ですか？ 私は断然育てる派です）}
```


### 画像の想定
作業風景・素材の接写・工房の灯りなど。完成品写真とトーンを揃える。

### CTAについて
この種の投稿には原則CTAを入れない（入れるとしてもフォロー誘導まで）。
BOOTHリンクは月に1〜2回、自然な文脈でのみ添える。
